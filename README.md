# IDS-Deep-Learning-Comparative-Analysis
Implemented &amp; Optimized Novel Deep Learning Models for IDS system. Algorithms implemented: LSTM, BiLSTM, GRU, BiGRU, TGAT, TransAD, TITAN, MHA. The models were compared on their parameter complexity, model size, validation loss, validation accuracy, Confusion Matrix (AUC, AUC-ROC, F1, Recall, Precision)
